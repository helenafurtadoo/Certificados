### Certificados e Formações

Repositório destinado à organização dos **certificados de cursos, formações e eventos** que fazem parte da minha trajetória acadêmica e profissional na área de tecnologia.

Aqui estão reunidos cursos complementares realizados principalmente nas áreas de **programação, desenvolvimento web e fundamentos da computação**.

## Cursos e conteúdos

### Python

Cursos envolvendo diferentes conceitos da linguagem Python, incluindo:

- Condicionais com `if`, `elif` e `else`
- Laços de repetição com `for` e `while`
- Listas e tuplas
- Conjuntos e dicionários
- Funções
- Strings e expressões regulares
- Programação assíncrona

Também faz parte deste repositório o certificado da **Jornada Python**, realizada pela Hashtag.

### Desenvolvimento Web

- HTML
- CSS
- Estrutura de páginas
- Ambientes de desenvolvimento
- Organização de arquivos e tags

### Lógica de Programação

- Fundamentos de lógica
- Pensamento computacional
- Introdução à programação com JavaScript

### Eventos

O repositório também reúne certificados de participação em eventos relacionados à tecnologia, como o **BrasíliaTI**.

## Objetivo

Além de organizar meus certificados, este repositório registra parte da minha evolução e dos conhecimentos adquiridos por meio de estudos realizados além da graduação.
